### 👋 关于我

我是 **忆丶未来**，一名全栈开发者。日常在 **Java / Spring Boot** 与 **Vue 3 / TypeScript** 之间来回横跳，也写一点 C# 桌面工具和 Python 小脚本。

喜欢把脑子里冒出来的东西做成能跑起来的产品：从数据库建模、接口设计到前端交互、部署上线，尽量自己走通一遍。技术上偏务实 —— 不追新，但会把选型理由和踩过的坑记下来。

业余时间维护 [**未来观测站**](https://yiweilai233.github.io)，把项目档案、开发日志和二次元收藏归档在里面。

```text
🔭 目前在折腾   易仓 WMS 的 AI 助手链路（FastAPI + Qdrant 向量检索）
🌱 正在学       RAG 工程化落地、Astro 内容站的可维护性
💬 可以聊聊     Spring Boot 工程化、Vue 3 组合式 API、个人站建设、AI 辅助编程
```
